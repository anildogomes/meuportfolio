# Anildo Gomes - Portfolio

Modern, responsive professional portfolio for **Anildo Gomes**, highlighting career paths in **Education**, **Business Management**, and **Technology**.

## Features

- **Multi-domain Profile**: Dedicated sections for Educator, Business, and Technology career paths.
- **Bilingual Support**: Instant toggle between Portuguese (`pt`) and English (`en`).
- **Dark / Light Theme**: Theme persistence with system preference detection and smooth transitions.
- **Dynamic Dates**: Smart computation of completion status and progress for degrees and certifications.
- **Print / PDF Friendly**: Formatted CV views ready for direct print/export to PDF per domain.
- **Rich Experience Details**: Markdown-rendered descriptions and project showcases.
- **Direct Contact & Socials**: Quick links to LinkedIn, GitHub, Instagram, X (Twitter), and Email.

## Tech Stack

- **React 18** with **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Motion** (Framer Motion v12)
- **Lucide Icons**
- **React Markdown**

## Development

```bash
npm install
npm run dev
```

The application will start on port `3000`.
